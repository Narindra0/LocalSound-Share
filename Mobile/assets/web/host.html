Le morceau à l’affiche +

Le titre du lecteur Windows se met à jour automatiquement, y compris pour YouTube si le navigateur le transmet. Gardez un seul lecteur actif pour éviter toute ambiguïté. Vous pouvez aussi corriger le titre ci-dessous.

La miniature du lecteur est récupérée automatiquement lorsqu’elle est disponible. Sinon, collez le lien de la vidéo en cours pour récupérer son titre et sa miniature.

Ce lien décrit la musique déjà partagée ; il ne lance pas la vidéo. En changeant de vidéo, actualisez le lien si la miniature n’est pas fournie par le lecteur.

La pochette du fichier ou du lecteur est utilisée lorsqu’elle est disponible. Vous pouvez choisir une image pour cette source.

04 / LE PARTAGE, À VOTRE FAÇON

Réglages du partage +

Lecture des réglages…

Ces deux préférences et le volume sont mémorisés dans ce navigateur.

La haute qualité conserve la stéréo à 48 kHz. Aucun changement automatique de qualité. L’écoute compatible PCM reste disponible pour les anciens lecteurs. Ce réglage reste actif jusqu’au redémarrage du serveur.

Le même délai est appliqué à tous les appareils. Il concerne les fichiers et les onglets ; le changement recale la lecture en cours. Il reste actif jusqu’au redémarrage du serveur.

À propos de la synchronisation

Les fichiers et les onglets utilisent une même horloge. En mode système, le son direct de Windows reste en avance. Pour les applications natives, un routage séparé est nécessaire.
