## Périmètre et mises à jour

Les signalements sont examinés sur la dernière version publiée. Il n’existe pas d’engagement de maintenance des anciennes versions.

LocalSound est prévu pour un **réseau local de confiance**. Les auditeurs n’ont pas de compte ni de code d’accès ; un appareil pouvant atteindre le serveur peut rejoindre le salon et proposer un morceau. Ne pas rediriger le port du salon vers Internet. La protection du réseau et l’authentification à YouTube restent distinctes de LocalSound.

Le navigateur YouTube intégré est isolé des API Node.js. L’édition Auditeur Léger utilise le Runtime WebView2 partagé et son propre dossier utilisateur. Consulter également la rubrique **À propos → Confidentialité** dans l’application pour les données traitées et leur emplacement.
